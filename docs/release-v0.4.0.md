本次发布提供 pith 桌面应用及 macOS、Windows 安装包，将聊天、资料入库、知识图谱、技能和定时任务整合到同一界面。

> 历史版本：macOS 安装包未采用 Developer ID 签名与苹果公证流程。新安装建议使用 [最新版本](https://github.com/l-zhi/pith-wiki/releases/latest)。

## 新增与改进

- 新增 Electron 桌面应用，提供持久化会话、资料收件箱、知识图谱、技能管理及设置界面。
- 支持一次性与周期性定时任务、日历和任务列表，并可在应用启动时补跑错过的任务。
- 引入可安装的提示词技能，以及 CLI 命令与 HTTP 网关集成；提供内置技能的安装机制。
- 默认启用出站敏感信息过滤，支持阻止发送和可还原脱敏。
- 改进日期范围检索、引用来源展示及文件产物访问。

## 修复

- 增加可配置的模型请求超时；工具循环达到上限时生成最终答复，避免长时间无输出。
- 改善知识库索引的新鲜度检测，并排除原始聊天记录目录。
- 修复文件输出路径重复及本地链接无法正确打开的问题。

## 下载与兼容性

下方 Assets 提供 Apple Silicon Mac、Intel Mac 和 Windows x64 安装包。定时任务由桌面应用执行，应用关闭期间不会持续运行。桌面端与 npm CLI 使用独立版本号。
